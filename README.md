# SITARA Admin

Aplikasi admin panel berbasis Vue 3 + Vite untuk SITARA.

## Instalasi

Pastikan Anda sudah menginstal Node.js dan npm terlebih dahulu.

1. Clone repository:
   ```bash
   git clone <repository-url>
   cd sitara-admin
   ```

2. Install dependency:
   ```bash
   npm install
   ```

3. Jalankan aplikasi secara lokal:
   ```bash
   npm run dev
   ```

4. Buka browser ke alamat yang ditampilkan oleh Vite, biasanya:
   ```text
   http://localhost:5173
   ```
